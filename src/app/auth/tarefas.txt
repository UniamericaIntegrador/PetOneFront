Configure o Keycloak Server na sua EC2:

Certifique-se de que o Keycloak está acessível via HTTPS
Crie um novo realm
Crie um novo client para seu frontend
Configure as URLs de redirecionamento permitidas
Configure o client como "public"


No seu frontend:

Copie os arquivos do código fornecido para sua estrutura de projeto
Ajuste as configurações do Keycloak no arquivo keycloak.js
Envolva sua aplicação com o AuthProvider


Configurações importantes no Keycloak:

Em seu client no Keycloak, configure:
CopyAccess Type: public
Valid Redirect URIs: http://seu-frontend/*
Web Origins: http://seu-frontend



Ajustes de CORS no backend:

Certifique-se de que seu backend aceita requisições da EC2 do frontend
Configure os headers adequados para CORS



Pontos importantes a considerar:

Segurança:

Use HTTPS em todas as EC2s
Configure corretamente os CORS
Mantenha o Keycloak atualizado


Performance:

O token é atualizado automaticamente quando necessário
Implementamos lazy loading para melhor performance


Integração com backend:

O token é automaticamente incluído em todas as requisições axios
O backend deve validar o token JWT do Keycloak

Implementação do Keycloak no AngularClick to open code
Para implementar, siga estes passos:

Instale as dependências:

bashCopynpm install keycloak-angular keycloak-js

Principais diferenças em relação ao React:

Usa o pacote keycloak-angular ao invés de apenas keycloak-js
Implementa a inicialização via APP_INITIALIZER
Usa Guards para proteção de rotas
Usa Interceptors para adicionar o token automaticamente
Aproveita o sistema de injeção de dependências do Angular


Estrutura do projeto:

O Guard protege as rotas automaticamente
O Interceptor adiciona o token em todas as requisições HTTP
O Service encapsula a lógica de autenticação
Os componentes podem usar o AuthService para acessar funcionalidades do Keycloak


Configuração adicional no app.module.ts:

typescriptCopyimport { HttpClientModule, HTTP_INTERCEPTORS } from '@angular/common/http';
import { AuthInterceptor } from './auth.interceptor';

@NgModule({
  imports: [
    HttpClientModule,
    KeycloakAngularModule
  ],
  providers: [
    {
      provide: HTTP_INTERCEPTORS,
      useClass: AuthInterceptor,
      multi: true
    }
  ]
})

Benefícios desta implementação:

Integração mais nativa com o Angular
Proteção de rotas automática
Gerenciamento de token automático
Fácil acesso aos roles e perfil do usuário
Tipagem forte com TypeScript



// app.module.ts
import { NgModule, APP_INITIALIZER } from '@angular/core';
import { KeycloakAngularModule, KeycloakService } from 'keycloak-angular';

function initializeKeycloak(keycloak: KeycloakService) {
  return () =>
    keycloak.init({
      config: {
        url: 'http://seu-servidor-keycloak:8080/auth',
        realm: 'seu-realm',
        clientId: 'seu-client-id'
      },
      initOptions: {
        onLoad: 'login-required',
        checkLoginIframe: false,
        pkceMethod: 'S256'
      }
    });
}

@NgModule({
  imports: [
    KeycloakAngularModule
  ],
  providers: [
    {
      provide: APP_INITIALIZER,
      useFactory: initializeKeycloak,
      multi: true,
      deps: [KeycloakService]
    }
  ]
})

export class AppModule { }
